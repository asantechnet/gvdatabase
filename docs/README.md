## Updating documentation

Create feature work records under ai/, update the relevant facts document alongside behavior changes, and keep facts/README.md indexed. Preserve historical records and existing links. A new plan is not a replacement for a maintained feature reference. The PWA consolidation preserved every existing document path; only navigation and historical labels were added.
