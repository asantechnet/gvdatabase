# Implementation plans and progress records

Keep one task-named Markdown record per implementation task here. Include findings, decisions, a full plan, progress and actual validation outcomes. Preserve older records as implementation history.

For current feature behavior, start with [docs/facts](../facts/README.md). The [PWA facts](../facts/pwa.md) and [background polling facts](../facts/background-polling.md) supersede descriptions in earlier PWA, deployment and visibility-only plans. For other features inspect the implementation and project instructions rather than assuming an old plan is current.
